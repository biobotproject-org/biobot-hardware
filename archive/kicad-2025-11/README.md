# Archived: KiCad sketch, November 2025

The first attempt at a carrier board, drawn in KiCad 9. It contains only a
Nano ESP32 module, an M.2 socket for the Notecard, a TCA9548A I2C
multiplexer, and one capacitor. The board file is empty; layout was
started and abandoned on 12 November 2025 (see the backups folder).

It was superseded by the Altium "Fire Detection Device" board in
`pcb/fire-detection-device/`. Kept for history only.
